# China Brand — вёрстка веб-приложения

Сервис, в котором нейросеть подбирает китайское название бренда с учётом культуры и ниши.

- **Вёрстка (GitHub Pages):** https://nwstcy.github.io/-HTML-CSS/
- **Макеты в Figma:** https://www.figma.com/design/JzspwWC8DtlXL5VBVnYkLU/%D0%B4%D1%80%D0%B0%D1%84%D1%82%D1%8B?node-id=18637-66

## Экраны

- «О проекте» — главная
- «Узнать больше»
- «Тарифы» и модалка оплаты
- Модалка регистрации и входа
- Переводчик: пустое состояние → выбор сферы → проверка данных → генерация → результат, плюс состояния ошибок

Сценарий: «Адаптировать бренд» → регистрация → выбор тарифа и оплата → переводчик.
Оплата демонстрационная: подходит любой 16-значный номер карты, срок ММ/ГГ и 3 цифры CVC.

## Структура

```
index.html      — разметка всех экранов и модалок
styles.css      — стили: CSS-переменные, flex/grid, адаптив (≤1024, ≤860, ≤640px)
script.js       — переключение экранов, регистрация, оплата
translator.js   — состояния переводчика и подсказки онбординга
img/            — картинки из макета
```

## Что использовано

- семантические теги: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, `dialog`, `form`
- CSS-переменные для цветов, шрифтов, кеглей, радиусов и отступов
- стили задаются классами, классы названы по смыслу (BEM): `plan-card`, `payment-form`, `wizard-step`, `request-history`, `onboarding-tip`
- раскладка на `display: flex` и `display: grid`
- адаптив под десктоп, планшет и мобильные
