# China Brand — версия на React (ДЗ №4)

Сервис, в котором нейросеть подбирает китайское название бренда с учётом сферы и звучания.
Проект из предыдущих заданий переписан на **React 19 + Vite**.

* Сайт (GitHub Pages): https://nwstcy.github.io/-HTML-CSS/
* Макеты в Figma: https://www.figma.com/design/JzspwWC8DtlXL5VBVnYkLU/%D0%B4%D1%80%D0%B0%D1%84%D1%82%D1%8B?node-id=18637-66

## Запуск

```bash
npm install
npm run dev      # локальный сервер разработки
npm run build    # сборка в папку dist
npm run preview  # просмотр собранной версии
```

Нужен Node.js 20.19 или новее.

## Структура

```
index.html                 — точка входа Vite, корневой <div id="root">
vite.config.js             — React-плагин, относительный base для GitHub Pages
src/
  main.jsx                 — монтирование приложения
  App.jsx                  — корневой компонент: связывает хуки и компоненты
  App.module.css
  styles/global.css        — дизайн-токены (CSS-переменные), сброс, адаптивные значения токенов
  components/              — каждый компонент в своей папке: Name.jsx + Name.module.css
    Sidebar/               — боковая панель: логотип, «Новый запрос», история, тариф
    HistoryList/           — «Недавние» и «Мои бренды»
    TopBar/                — верхняя панель на телефоне
    Chat/                  — экран диалога: выбирает, что показать на каждом шаге
    Message/               — сообщение, вопрос, «пузырь» пользователя, кнопки под репликой
    Intro/                 — приветствие нейросети (сворачивается после ввода бренда)
    SpherePicker/          — выбор сферы: три уровня, «хлебные крошки», «Назад»
    Brief/                 — проверка данных перед генерацией
    Thinking/              — индикатор генерации
    Result/, Variant/      — результат и один вариант названия
    SpeakButton/           — «Послушать произношение»
    Composer/              — поле ввода, микрофон, отправка / остановка
    Alert/                 — ошибка обработки и исчерпанный лимит
    Modal/, Toast/, Tooltip/ — модальное окно, уведомление, подсказка
    Button/, ToolButton/, Icon/, Avatar/, AnimatedText/ — общие элементы
  hooks/
    useTranslator.js       — состояние сценария: история, шаг, сфера, генерация, ошибки
    useSpeechRecognition.js — голосовой ввод (Web Speech API)
    useSpeechSynthesis.js  — озвучка китайского названия (Web Speech API)
    useSeenTips.js         — закрытые подсказки онбординга
    useToast.js            — короткие уведомления
  lib/                     — логика без интерфейса: генератор, речь, localStorage, буфер обмена
  data/data.js             — справочник сфер, известные бренды, таблицы иероглифов
```

## ДЗ №4. React — как выполнены критерии

* **Полностью на React, без прямых обращений к DOM.** Весь интерфейс описан в JSX и строится из состояния. Нет `querySelector`, `innerHTML`, `classList`, `addEventListener` на элементах. События — через пропсы `onClick`, `onSubmit`, `onChange`, `onKeyDown`. Фокус поля ввода и прокрутка диалога — через `useRef`. Единственное обращение к `document` — стандартное монтирование `createRoot(document.getElementById('root'))`.
* **Компоненты в отдельных файлах и папках.** 23 компонента, у каждого своя папка `components/Name/` с `Name.jsx` и `Name.module.css`.
* **Модульные стили.** У каждого компонента CSS-модуль (`*.module.css`), классы подключаются как `styles.className` и в сборке получают уникальные имена. Общими остаются только дизайн-токены в `global.css`. Анимации (`@keyframes`) объявлены внутри модулей, которые их используют.
* **Хуки.**
  * `useState` — шаг сценария, история, выбор сферы, текст поля ввода, открытое меню, модальное окно, анимация повтора;
  * `useEffect` — сохранение истории в `localStorage`, автопрокрутка, фокус, остановка озвучки при смене экрана;
  * `useRef` — таймер генерации, ссылки на элементы для прокрутки и фокуса;
  * `useCallback` — стабильные обработчики голосового ввода и уведомлений;
  * `useId` — уникальные id градиентов в аватаре;
  * собственные хуки: `useTranslator`, `useSpeechRecognition`, `useSpeechSynthesis`, `useSeenTips`, `useToast`.

## Что сохранилось из прошлых заданий

* Вёрстка по макету: CSS-переменные, flex/grid, адаптив (≤1100, ≤900, ≤760, ≤480px), семантические теги.
* Анимации, как в ИИ-сервисах: появление сообщений с размытием, текст по словам, иероглифы по одному, переливающийся текст во время генерации.
* Web Speech API: голосовой ввод и озвучка с обработкой ошибок. Web Storage API: история и «Мои бренды» сохраняются между визитами.

## Публикация на GitHub Pages

Сборку делает GitHub Actions (`.github/workflows/deploy.yml` в корне репозитория): при каждом изменении ветки `main` проект собирается командой `npm run build`, а папка `dist` публикуется на GitHub Pages. В настройках репозитория **Settings → Pages → Source** должно быть выбрано **GitHub Actions**.
