# China Brand — вёрстка веб-приложения

Сервис, в котором нейросеть подбирает китайское название бренда с учётом сферы и звучания.

* Вёрстка (GitHub Pages): https://nwstcy.github.io/-HTML-CSS/
* Макеты в Figma: https://www.figma.com/design/JzspwWC8DtlXL5VBVnYkLU/%D0%B4%D1%80%D0%B0%D1%84%D1%82%D1%8B?node-id=18637-66

## Экраны и состояния

* Переводчик, пустое состояние — приветствие и ввод названия бренда
* Выбор сферы — три уровня категорий с «хлебными крошками», кнопками «Назад» и «Применить» и ручным вводом
* Проверка данных — «Бренд / Сфера», копирование и редактирование сферы с сохранением истории диалога
* Генерация — индикатор загрузки и кнопка «Остановить генерацию»
* Результат — адаптация с учётом сферы и вариант по звучанию: иероглифы, пиньинь, объяснение
* Сохранение в «Мои бренды», копирование, повторная генерация
* Боковая панель — «Новый запрос», «Недавние», «Мои бренды», удаление из истории с подтверждением
* Ошибки — «Название не удалось обработать» и «Лимит генераций исчерпан»
* Подсказки онбординга для нового пользователя

Сценарий: введите название бренда → выберите сферу → «Адаптировать бренд» → результат.
Генерация демонстрационная: для BMW и нескольких известных брендов (Apple, Nike, IKEA и др.) показываются их настоящие китайские названия, для остальных название собирается по звучанию и смыслу сферы.

Как вызвать ошибки:
* название без букв (например, `123`) — «Название не удалось обработать»;
* четвёртая генерация подряд — «Лимит генераций исчерпан» («Обновить» сбрасывает лимит).

## Структура

```
index.html   — разметка приложения, модальное окно подтверждения, спрайт иконок из макета
styles.css   — стили: CSS-переменные, flex/grid, анимации, адаптив (≤1100, ≤900, ≤760, ≤480px)
app.js       — состояния переводчика, выбор сферы, история, подсказки, переходы между экранами
.nojekyll    — отключает сборку Jekyll на GitHub Pages
```

## Что использовано

* семантические теги: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, `form`, списки `ol`/`ul` для диалога и истории
* CSS-переменные для цветов, шрифтов, кеглей, радиусов, размеров и длительности анимаций
* стили задаются классами, классы названы по смыслу (BEM): `sidebar`, `history__item`, `sphere-picker`, `sphere-chip`, `composer`, `adaptation`, `variant__hanzi`, `tooltip`, `alert--limit`
* раскладка на `display: flex` и `display: grid` (каркас приложения и сетка сфер — grid)
* адаптив под десктоп, планшет и мобильные: на телефоне боковая панель становится выезжающим меню, сетка сфер — 3 → 2 → 1 колонка
* анимации переходов, как в ИИ-сервисах: появление сообщений с размытием, проявление текста по словам и иероглифов по одному, переливающийся текст во время генерации, смена экранов через View Transitions API; при настройке «уменьшить движение» анимации отключаются
* иконки — контуры Remix Icon, извлечённые из макета
