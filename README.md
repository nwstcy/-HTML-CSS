# China Brand — веб-приложение на HTML, CSS и JavaScript

Сервис, в котором нейросеть подбирает китайское название бренда с учётом сферы и звучания.

* Сайт (GitHub Pages): https://nwstcy.github.io/-HTML-CSS/
* Макеты в Figma: https://www.figma.com/design/JzspwWC8DtlXL5VBVnYkLU/%D0%B4%D1%80%D0%B0%D1%84%D1%82%D1%8B?node-id=18637-66

## Что умеет приложение

* Переводчик: ввод бренда → выбор сферы → проверка данных → генерация → результат
* Выбор сферы — дерево из трёх уровней с «хлебными крошками», кнопками «Назад» и «Применить» и ручным вводом
* Редактирование сферы с сохранением истории диалога, копирование запроса и результата
* Результат — адаптация с учётом сферы и вариант по звучанию: иероглифы, пиньинь, объяснение; повторная генерация
* «Недавние» и «Мои бренды» в боковой панели, удаление из истории с подтверждением в модальном окне
* Ошибки — «Название не удалось обработать» и «Лимит генераций исчерпан»
* Подсказки онбординга для нового пользователя (закрытые запоминаются в `localStorage`)
* Голосовой ввод названия бренда и сферы (кнопка микрофона в поле ввода)
* Прослушивание произношения китайского названия (кнопка рядом с иероглифами)
* История и «Мои бренды» сохраняются между визитами

Генерация демонстрационная: для BMW и известных брендов (Apple, Nike, IKEA и др.) показываются их настоящие китайские названия, для остальных название собирается по звучанию и смыслу сферы.
Как вызвать ошибки: название без букв (например, `123`) или четвёртая генерация подряд.

## ДЗ №3. Браузерные API

### Web Speech API — основное

China Brand подбирает название, которое должно хорошо **звучать** по-китайски, поэтому речь здесь по делу:

* **Синтез речи (`speechSynthesis`)** — кнопка с динамиком рядом с иероглифами произносит название на путунхуа (`zh-CN`, замедленный темп 0.8). Пользователь, который не читает пиньинь, сразу слышит, как бренд будет звучать для китайского покупателя. Повторное нажатие останавливает звук; при смене экрана озвучка прерывается.
* **Распознавание речи (`SpeechRecognition`)** — кнопка микрофона в поле ввода. Можно назвать бренд или сферу голосом: текст появляется в поле по мере речи, пользователь проверяет его и отправляет. Во время записи кнопка пульсирует, в поле написано «Говорите…».

Обработанные сценарии и ошибки:

| Ситуация | Что видит пользователь |
|---|---|
| Браузер не поддерживает распознавание (например, Firefox) | Кнопка микрофона полупрозрачная, при нажатии — «Голосовой ввод не поддерживается в этом браузере…» |
| Страница открыта не по https | «Голосовой ввод работает только на защищённом соединении» |
| Пользователь запретил микрофон (`not-allowed`) | «Нет доступа к микрофону. Разрешите его в настройках браузера» |
| Микрофона нет (`audio-capture`) | «Микрофон не найден» |
| Тишина (`no-speech`) | «Ничего не расслышали…» |
| Нет интернета (`network`) | «Для распознавания речи нужен интернет» |
| Браузер не поддерживает синтез речи | Кнопки «Послушать» полупрозрачные, при нажатии — «Озвучка не поддерживается» |
| В системе нет китайского голоса | «В системе нет китайского голоса. Его можно добавить в настройках языка и речи» |
| Ошибка воспроизведения | «Не удалось воспроизвести произношение» |

Все сообщения показываются в уведомлении внизу экрана, приложение продолжает работать без голоса.

### Web Storage API (localStorage) — дополнительно

«Недавние» и «Мои бренды» сохраняются в `localStorage` и восстанавливаются после перезагрузки страницы. Если хранилище недоступно (приватный режим, запрет cookies, переполнение) или данные повреждены, приложение работает как раньше, история живёт до перезагрузки, а пользователь один раз получает предупреждение.

### Как устроен код

* `speech.js` работает только с API: проверяет поддержку, запускает распознавание и синтез, переводит коды ошибок браузера в понятные тексты. Об интерфейсе модуль ничего не знает.
* `voice.js` связывает API с интерфейсом: состояние кнопок, текст в поле ввода, уведомления.
* `storage.js` сохраняет и читает историю, проверяя данные перед использованием.

### Браузеры

* Chrome, Edge, Safari (macOS и iOS) — голосовой ввод и озвучка.
* Firefox — озвучка; голосового ввода там нет, срабатывает сообщение о неподдержке.
* Голосовой ввод требует https (на GitHub Pages он есть). В Chrome распознавание идёт через серверы Google, поэтому нужен интернет.

## ДЗ №2. JavaScript — как выполнены критерии

* **Динамическое создание и изменение DOM.** Сообщения диалога, сетка сфер, результат, списки истории, подсказки и уведомления создаются из JS (`createElement`, `append`, `replaceChildren`, `innerHTML`) и меняются через `classList`, `hidden`, `dataset`.
* **Данные в JS-структурах.** Дерево сфер — массив объектов `SPHERES`; известные бренды и иероглифы — объекты `KNOWN`, `MEANINGS`, `SYLLABLES`; состояние — объект `state`, история — массив запросов `state.sessions`. Списки «Недавние» и «Мои бренды» каждый раз строятся из этого массива.
* **Обработка событий.** `submit` формы ввода, `input` при наборе текста, `click` (через делегирование по `data-action`), `keydown` (Esc), `animationend`.
* **ES-модули.** Код разделён на модули с `import`/`export`, подключение — `<script type="module" src="main.js">`.
* **Без ошибок в консоли.** Весь сценарий проверен в браузере.

## Запуск локально

ES-модули не работают, если открыть `index.html` двойным щелчком. Запустите локальный сервер в папке проекта, например `python -m http.server`, и откройте http://localhost:8000, или используйте расширение Live Server в VS Code.
